# Сборка на Windows

[English](build-windows.md) · **Русский**

Оконный сборщик автора (RepoQuestBuilder 1.0.7 из релизов Dobutsu) содержит набор под 0.4.4.3 и R.E.P.O. 0.5.0
собрать не может. Этот форк собирает той же цепочкой из командной строки: `scripts/build-windows.ps1` по шагам делает
всё то же, что делала программа.

> Скрипт для Windows повторяет скрипт для macOS, проверенный пока только он. Если что-то упало — откройте
> [issue](https://github.com/crimecock/repo-quest-vr/issues) и приложите `C:\RepoQuest\work\logs\builder.log` (и `unity-build.log`, если дошло до Unity).

## Что нужно

- Windows 10/11 64-бит, 16 ГБ ОЗУ, **около 60 ГБ свободного места** на диске с рабочей папкой (по умолчанию `C:\RepoQuest`).
- **R.E.P.O. 0.5.0**, установленная в Steam (сборщик сам найдёт её в библиотеках Steam).
- **Meta Quest** (сделано и проверяется на Quest 3) в **режиме разработчика** и USB-кабель.
- **Unity Hub** и бесплатный аккаунт Unity.
- [Git для Windows](https://git-scm.com/download/win) — или скачайте код ZIP-архивом (ниже).

**.NET 8 SDK** скрипт поставит сам, если его нет. Всё остальное (AssetRipper, Python с пакетами, BepInEx, пакеты
NuGet, встроенные шейдеры Unity) сборщик скачает сам, каждое из первоисточника.

## 1. Установите Unity 6000.3.17f1 с Android

Откройте в браузере ссылку (Unity Hub откроется на нужной версии):

```
unityhub://6000.3.17f1/cf0352b38e81
```

В списке модулей отметьте **Android Build Support** и внутри него **OpenJDK** и **Android SDK & NDK Tools**, установите
(около 10 ГБ). Место установки оставьте по умолчанию (`C:\Program Files\Unity\Hub\Editor\6000.3.17f1`) или потом
укажите скрипту `-Unity`.

## 2. Скачайте код

С Git, в PowerShell, в папке, путь к которой только латиницей и без пробелов (например `C:\src`):

```powershell
git clone https://github.com/crimecock/repo-quest-vr.git
cd repo-quest-vr
```

Без Git: на странице репозитория **Code → Download ZIP**, распакуйте в такую папку и откройте в ней PowerShell.

## 3. Подготовьте шлем

1. Включите **режим разработчика** для шлема в приложении Meta Horizon на телефоне.
2. Подключите Quest к ПК по USB, наденьте шлем и разрешите **отладку по USB** (с галочкой «всегда разрешать с этого компьютера»).

## 4. Соберите

```powershell
powershell -ExecutionPolicy Bypass -File scripts\build-windows.ps1
```

Скрипт:

1. проверит Unity 6000.3.17f1 с Android (если её нет — откроет Unity Hub на ней);
2. при необходимости поставит .NET 8 SDK;
3. скачает набор порта из ветки `kit` этого форка и проверит его SHA-256;
4. соберёт сборщик и запустит его: экспорт AssetRipper, RepoXR внутрь игры, Unity-проект, Unity → APK;
5. поставит APK в шлем.

**Первая сборка — 1–1,5 часа на быстром ПК и 3–5 часов на медленном** (Unity один раз импортирует игру и компилирует
шейдеры). Следующие используют готовое и идут 20–40 минут. Не давайте ПК уснуть — сборщик сам блокирует сон, пока
работает.

Параметры:

| Параметр | Что делает |
|---|---|
| `-Game "D:\SteamLibrary\steamapps\common\REPO"` | Папка игры (та, где `REPO_Data`), если не нашлась сама |
| `-Unity "D:\Unity\6000.3.17f1"` | Папка Unity (та, где `Editor\Unity.exe`), если она в другом месте |
| `-Workspace D:\RepoQuest` | Другая рабочая папка (латиница, без пробелов) |
| `-NoInstall` | Только собрать; APK будет в `<рабочая папка>\work\build` |
| `-CodeOnly` | Поменялся только код (новый набор с новыми DLL или патчами): данные игры берутся из прошлого APK, сборка втрое быстрее. Если прошлой сборки нет — полная |

Для скорости можно добавить рабочую папку в исключения Безопасности Windows (Защита от вирусов и угроз → Управление
настройками → Исключения): иначе Defender проверяет каждый из десятков тысяч файлов, которые пишет сборка.

## 5. Играйте

В шлеме: **Библиотека → Неизвестные источники → R.E.P.O.** Одиночная игра работает сразу. Для мультиплеера войдите в
Steam кнопкой **Steam** в главном меню (про неофициальный клиент Steam — в README).

Настройки производительности: *Настройки → VR Settings → Rendering* (Level Culling и его дистанции, Pixel Lights,
Lamp Lighting, Post Processing). Управление: [controls.ru.md](controls.ru.md).

**Не делитесь APK**: в нём файлы игры. Каждый собирает свой.

## Обновление

```powershell
git pull
powershell -ExecutionPolicy Bypass -File scripts\build-windows.ps1
```

Когда R.E.P.O. обновится в Steam, сборке могут понадобиться правки в этом репозитории — загляните в issues.

## Если что-то не так

| Проблема | Что делать |
|---|---|
| `выполнение сценариев отключено в этой системе` | Запускайте ровно как выше: `powershell -ExecutionPolicy Bypass -File ...` |
| `Unity ... not found` | Установите её (шаг 1) или укажите `-Unity` |
| `the work folder must be an ASCII path` | Укажите `-Workspace` с путём вроде `D:\RepoQuest` |
| `no headset` или `install failed` после сборки | APK собран, поставьте его вручную: [install.ru.md](install.ru.md) (подключение, ошибки `INSTALL_FAILED_…`, переустановка без потери сохранений) |
| Сборка остановилась с ошибкой | Логи в `C:\RepoQuest\work\logs`; после исправления запустите скрипт снова — готовые шаги пропускаются |
