# Игра в шлеме

[English](playing.md) · **Русский**

Всё, что после установки APK на Quest: запуск, управление, настройки VR, мультиплеер и что прислать, если что-то не
так. Сборка и установка: [README](../README.ru.md), [install.ru.md](install.ru.md).

> Всё ниже работает на Quest 3 (1.0.7-qc27). Значения по умолчанию и названия настроек взяты из кода RepoXR и патчей
> этого форка; что каждая новинка 0.5.0 делает в VR — в [repo-0.5.0.ru.md](repo-0.5.0.ru.md#новое-в-repo-050-и-как-оно-работает-в-vr).

## Запуск

В шлеме: **Библиотека → Неизвестные источники → R.E.P.O.** Первый запуск после установки дольше обычного (игра
распаковывает файлы RepoXR). Разрешите микрофон, когда игра спросит, иначе голосовой чат будет молчать.

Главное меню висит перед вами. Наведите на него любой контроллер и нажмите **курок**; длинный луч остаётся у руки,
которой нажимали последней.

## Управление

Все кнопки и жесты руками: **[controls.ru.md](controls.ru.md)**. Коротко:

| | Левый контроллер | Правый контроллер |
|---|---|---|
| Стик | Ходьба; нажатие: чат; удержание: колесо эмоций | Поворот; вверх/вниз: толкнуть/притянуть предмет, прокрутка в меню; нажатие: присесть |
| Курок | Бег | Луч захвата |
| Хват (grip) | Вращать предмет в руке (правым стиком) | Взаимодействие |
| Кнопки | ≡ (кнопка меню): меню · X: выключить микрофон · Y: сброс роста | A: прыжок · B: кувырок |

Техника: наведите луч на сиденье или руль и один раз нажмите правый курок — вы сели; едете левым стиком; ещё одно
нажатие курка — слезть ([controls.ru.md](controls.ru.md#техника)).

Карта: рука к поясу (где висит карта) или к плечу, держать хват. Фонарик на голову: другая рука к виску, хват. Инвентарь: наведите предмет в руке на
ячейку; достать — доминирующей рукой в ячейку и курок.

Кнопки можно переназначить в игре: *Settings → Controls* показывает VR-действия RepoXR.

## Настройки VR

*Settings → VR Settings*. Это настройки RepoXR; они хранятся в шлеме и не сбрасываются при установке новой сборки.

**Gameplay**

| Настройка | По умолчанию | Что делает |
|---|---|---|
| Head Bob | 0 % | Покачивание камеры при ходьбе относительно игрового. В порте по умолчанию выключено (укачивание) |
| Roomscale Crouch | вкл | Присели в жизни — присели в игре. Выключите, если играете сидя |
| Dominant Hand | Right | Рука, которой хватаете; Left меняет контроллеры местами |
| Arms | Attached | Detached: руки летают свободно, без привязки к телу |
| Haptic Feedback | All | All / Reduced / Off — вибрация |
| Reduced Aim Impact | выкл | Ослабляет принудительный поворот взгляда (глаз на потолке и т. п.), помогает при укачивании |

**Input**

| Настройка | По умолчанию | Что делает |
|---|---|---|
| Turn Provider | Smooth | Плавный / рывками (Snap) / выключен; переключается сразу, без перезапуска |
| Smooth Turn Speed Modifier, Analog Smooth Turn | 1×, вкл | Скорость плавного поворота и зависит ли она от наклона стика |
| Snap Turn Size | 45° | Угол поворота рывком |
| Normalize Movement | выкл | Всегда полная скорость, как бы слабо ни наклонили стик |
| Vehicle direction source | Hand | Куда едет техника: куда смотрит рука или голова |

**UI**: высота HUD (HUD Height и HUD Secondary Height — когда смотрите на него), расстояние до плавающего холста
(Smooth Canvas Distance).

**Rendering** (здесь всё, что настроено под Quest)

| Настройка | По умолчанию | Что делает |
|---|---|---|
| Camera Resolution | 100 % | Масштаб рендера. Меньше — быстрее и мыльнее |
| Pixel Lights | 1 | Сколько источников освещают объект в полном качестве. Больше — красивее и медленнее (в игре на ПК 12) |
| Lamp Lighting | вкл | Лампы освещаются попиксельно за один проход шейдерами порта: без швов и легче, но лампы не дают теней |
| Other Flashlight Shadows | выкл | Тени от фонариков других игроков: 7–10 мс видеочипа на кадр при полном лобби |
| Level Culling | вкл | Дальние части уровня не рисуются: мелочь дальше *Small Object Distance*, всё дальше *Room Distance*. Меняется только отрисовка: объекты работают, мультиплеер не затронут |
| Small Object Distance | 20 м | Пропы, ценности и предметы меньше 1,5 м не рисуются дальше этого |
| Room Distance | 0 м | Дальше этого не рисуется ничего; 0 — докуда видно сквозь туман (разницы не видно). Меньше — прячутся дальние комнаты, быстрее |
| Post Processing | выкл | Цветокоррекция, виньетка, зерно игры. Выключено — ярче и около 5 мс видеочипа экономии |
| Render Mode | Single Pass | Оба глаза за один проход. *Multipass* рисует их по очереди: примерно на 25 % медленнее, зато видно зеркало в магазине. После смены — перезапуск игры |
| Shop Mirror | вкл | Зеркало у косметического автомата (при Single Pass скрыто всё равно) |
| FPS Counter | выкл | Частота кадров внизу слева в поле зрения: FPS, средний и самый долгий кадр за последние полсекунды (и время процессора и видеочипа, если шлем их отдаёт). Зелёный от 68 FPS, жёлтый от 50, ниже — красный |

Собственные настройки игры тоже действуют там, где это имеет смысл. В R.E.P.O. 0.5.0 появилась настройка **Item
Unequip Auto Hold** (*Настройки → Gameplay*, по умолчанию включена): предмет, который вы достали из слота инвентаря,
остаётся на луче и после того, как вы отпустили курок, — до следующего нажатия. Выключите её, если хотите, чтобы он
падал, как только отпустите.

## Зеркало в магазине

В R.E.P.O. 0.5.0 в магазине рядом с косметическим автоматом есть зеркало. На Quest оно **по умолчанию скрыто** — так
задумано. Quest рисует оба глаза за один проход (*single-pass*), а у зеркала игры одна картинка отражения; зеркалу
нужна своя картинка для каждого глаза, и в single-pass хотя бы в одном глазу оно выглядело бы неправильно. Если рисовать
глаза по очереди (*multi-pass*), порт рисует отражение для каждого глаза, и зеркало работает, как на ПК, — но тогда
дороже становится вся игра: сцена отправляется на отрисовку отдельно для каждого глаза, и FPS заметно падает.

Чтобы всё-таки включить: *VR Settings → Rendering → Render Mode* = **Multipass** и перезапустите игру (или
`SinglePassRendering = false` в `RepoXR/config/io.daxcess.repoxr.cfg` в шлеме); *Shop Mirror* там же снова его выключает.

## Сидя

Сядьте так, как будете играть, и нажмите **Y**: текущая высота головы станет ростом стоя. Выключите **Roomscale
Crouch**, иначе взгляд вниз будет считаться приседанием.

## Мультиплеер

Одиночная игра работает без сети. Для игры по сети войдите в Steam кнопкой **Steam** в главном меню, рядом с *Quit
Game*: имя аккаунта (не имя профиля), пароль, затем Steam Guard (подтвердите вход в приложении Steam или введите код из
него или из письма). Для ввода под меню появляется клавиатура RepoXR. Игра переключается на аккаунт без перезапуска.

> В 0.5.0 кнопки главного меню переехали; кнопка Steam снова на месте начиная с 1.0.7-qc4.

После входа шлем работает со Steam напрямую через [SteamKit2](https://github.com/SteamRE/SteamKit) — неофициальный
клиент Steam. Правила Steam не разрешают сторонние клиенты; риск для аккаунта небольшой, но он есть.

На Quest игра упирается в процессор. Лучше всего играть **клиентом у хоста на ПК**: врагов и физику считает хост.

## Файлы в шлеме

`/sdcard/Android/data/io.repoxr.quest/files/` (доступны через `adb`; Android стирает их при удалении игры — как
сохранить, см. [install.ru.md](install.ru.md#переустановка-с-сохранением-данных)):

| Файл | Что это |
|---|---|
| `RepoXR/config/io.daxcess.repoxr.cfg` | Настройки VR, описанные выше |
| `perf-levels-off` (пустой) | Оставить частоты процессора и видеочипа системе вместо SUSTAINED_HIGH |
| `culling.txt` | Перекрывает Level Culling для тестов: строки `small=20`, `size=1.5`, `far=0` или `off` |

## Известные проблемы

Всё работает: проверено на ПК, а Quest собирает тот же код. Полезно знать:

- Одна мелочь: **страница «Язык»** (*Настройки → Язык*) в VR показывает только Text to Speech — кнопки языков оказываются за пределами меню. Исправление готово и придёт со следующей сборкой.

- Зеркало в магазине по умолчанию скрыто, так задумано: см. [Зеркало в магазине](#зеркало-в-магазине).
- Хлыст: бросок работает, только когда хлыст что-то поймал. Чувствительность: VR Settings → Input → *Whip Sideways /
  Crack Sensitivity*.

## Если что-то не так

Пришлите вместе с описанием (adb есть в Android-модуле Unity, см. [install.ru.md](install.ru.md#2-найдите-adb)):

1. **Лог игры.** Буфер логов в шлеме маленький, поэтому пишите его во время запуска:
   ```bash
   adb logcat -c && adb logcat -s Unity AndroidRuntime CRASH > logcat-unity.txt
   ```
   Запустите игру, повторите проблему, остановите запись Ctrl+C.
2. **Снимок сцены** (камеры, холсты, рендер-текстуры) — игра запущена, шлем надет:
   ```bash
   adb shell touch /sdcard/Android/data/io.repoxr.quest/files/diag-request
   ```
   ```bash
   adb pull /sdcard/Android/data/io.repoxr.quest/files/diag diag
   ```
3. **Видео**, записанное в шлеме (кнопка Meta → камера → запись):
   ```bash
   adb pull /sdcard/Oculus/VideoShots videos
   ```
