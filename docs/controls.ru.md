# Управление R.E.P.O. VR на Quest 3

[English](controls.md) · **Русский**

Раскладка по умолчанию из RepoXR (набор действий `VRInputs`, профиль Meta Quest). Её можно поменять в настройках игры: Настройки → Управление (RepoXR показывает там свои действия). Для левши в настройках RepoXR есть «ведущая рука — левая», тогда руки меняются местами.

> Составлено по коду RepoXR 1.2.3 (набор действий по умолчанию); проверка в шлеме идёт.

## Кнопки

| Контроллер | Что делает |
|---|---|
| **Левый стик** | Ходьба |
| **Левый стик, нажать коротко** | Чат |
| **Левый стик, зажать (0,3 с)** | Колесо эмоций |
| **Левый курок** | Бег |
| **Левый grip** | Вращать объект в руке (вместе с правым стиком) |
| **X** | Меню (пауза) |
| **Y** | Сбросить рост (откалиброваться заново) |
| **Правый стик влево/вправо** | Поворот (по умолчанию плавный; в настройках RepoXR можно рывками по 45°) |
| **Правый стик вверх/вниз** | С объектом в руке — оттолкнуть или притянуть; в меню и списках — прокрутка |
| **Правый стик, нажать** | Присесть |
| **Правый курок** | Схватить (луч захвата) |
| **Правый grip** | Взаимодействовать (двери, кнопки, рычаги) |
| **A** | Прыжок |
| **B** | Кувырок (tumble) |

## Руками

- **Карта:** поднеси любую руку к плечу. Контроллер дрогнет, тогда зажми **grip** этой руки — карта окажется в руке. Отпусти grip, и карта уберётся. На бегу не достаётся.
- **Фонарь на голову:** поднеси вторую руку (не ведущую) к голове сбоку и нажми **grip**. Нажми ещё раз — фонарь вернётся в руку.
- **Инвентарь (3 слота):**
  - *положить:* держи предмет лучом. Слоты увеличатся и выйдут вперёд. Наведи луч с предметом на слот;
  - *достать:* сунь ведущую руку в слот с предметом и нажми **правый курок**.
- **Эмоции:** зажми левый стик — откроется колесо. Наведи руку на эмоцию и нажми **курок этой руки** — эмоция включится или выключится. Повторное зажатие стика закрывает колесо.
- **Меню и интерфейс:** луч из руки и **курок**. Клавиатура RepoXR появляется под меню, когда нужно ввести текст (вход в Steam, пароль лобби).

## Если погиб

- **Правый курок / левый курок** — следующий / предыдущий игрок в режиме наблюдения.

## Сидя

Сядь так, как будешь играть, и нажми **Y**. Игра примет текущую высоту головы за рост стоя, и персонаж будет «стоять», пока ты сидишь. Ещё в настройках RepoXR (Gameplay) стоит выключить **Roomscale Crouch**: иначе наклон головы вниз сидя игра посчитает приседанием.

## Голос

Микрофон работает по настройкам самой игры (Настройки → Звук: активация голосом или push-to-talk). На контроллере у push-to-talk кнопки нет. Если нужен этот режим — назначь действие PushToTalk на свободную кнопку в настройках управления.
