# Kit downloads

The kit that `scripts/build-mac.sh` and `scripts/build-windows.ps1` on the `repo-0.5.0` branch download: the port's
scripts, Unity tooling and prebuilt RepoXR (1.2.3 + patches 0001-0009), RepoXR.Standalone and SteamShim, built from
this repository's sources. **No game files**: the game is built from your own Steam copy. License: GPL-3.0 (see the
kit's `SOURCES.md` and `licenses/`).

Набор, который скачивают `scripts/build-mac.sh` и `scripts/build-windows.ps1` из ветки `repo-0.5.0`: скрипты порта,
Unity-инструменты и собранные RepoXR (1.2.3 + патчи 0001-0009), RepoXR.Standalone и SteamShim из исходников этого
репозитория. **Файлов игры нет**: игра собирается из вашей копии в Steam.
